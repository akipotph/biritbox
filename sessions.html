How it works

Listen only

Listen opens the Birit Box app. You hear the singers and see the lyrics and scores — clap, cheer and chat. No mic.

10-minute guest code

You get in with a temporary guest code — never the session's own code. After 10 minutes, wait 5 and ask for a new one.

The host lets you in

Every listener knocks first. The host taps Allow or Deny, and can remove anyone. Up to 5 listeners.

1-hour turns

Each public session lasts 1 hour, so every pub gets a fair turn. Hosts can start a new one right after.

Pub #

Every pub has its own number that stays the same — it's how you find your favorite pubs. It's not a join code.
